MICROSOFT SEMANTIC KERNEL FOR JAVA

Semantic Kernel Java 教学演示

demo01 ~ demo11 渐进式教学 · SDK 1.5.0 + Spring Boot 3.4.4 + Java 21

本工程用 11 个循序渐进的 Demo 带零基础读者上手 Microsoft Semantic Kernel for Java——一个面向企业级应用的 LLM 编排框架，核心概念是 Kernel（内核）+ Plugin（函数插件）+ ChatHistory（对话历史）。所有示例都采用 OpenAI 兼容协议，可对接本地网关（vLLM / Ollama 等）。
